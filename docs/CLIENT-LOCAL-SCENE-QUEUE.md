# 客户端场景排队

场景之间的排队与 subagent 开关无关。其他场景仍在执行或等待回复时，新场景任务留在客户端；单个场景可以自行调用 subagent，不自动注入跨场景上下文。

队列使用 IndexedDB，按 Being endpoint 隔离，保存正文、附件、场景和入队顺序。恢复后先检查真实 active breath，再决定出队。发送前持久记录 sending；刷新打断发送时，该记录标记“发送状态待确认”，不会自动重发，可核对历史后取消。
