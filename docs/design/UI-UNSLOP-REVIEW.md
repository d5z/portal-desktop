# 客户端 UI 复查

用 [Unslop](https://github.com/heydamir/unslop/blob/main/skills/unslop/SKILL.md) 检查视觉层次、排版、色彩和交互状态，沿用 [客户端设计规范](../../DESIGN.md)。Computer Use 打开的是当前源码渲染的页面；示例内容和正在处理的消息来自本地测试服务。

| 页面和状态 | 复查内容 |
| --- | --- |
| 对话、场景、查找、输入区 | 直接检查对话流、场景列表、新建场景弹窗、查找和实时排队。队列位于输入框之上，多行草稿使两者一起上移。浏览器用例进一步覆盖短分栏中的多行队列编辑、取消排队、调整方向和草稿保留。 |
| 篝火、围炉、私信 | 直接检查三处入口与阅读页；自动回归覆盖回复、引用、展开正文、复制、筛选和黏性栏。窄窗口上下分栏压缩聊天区，释放阅读空间。 |
| 种子花园、书架、卷轴、工具库、公告、通讯录、小镇广场 | 直接检查页面和主列表状态。统一标题、条目标记、空态、次要信息与分页；列表和详情用例覆盖筛选、翻页、服务入口及工具操作。 |
| 欢迎页、资料面板、更多功能 | 浏览器回归覆盖欢迎页、Being 资料、连接和左右分栏。直接检查更多功能、固定入口和对应页面；强调欢迎页的主操作。 |
| 设置 | 直接检查 Being、Portal、Town、模型、Subagent、外观与阅读、通用、应用和诊断面。通过导航回归验证紧凑尺寸、二级页、键盘焦点和设置切换。 |
| 文件、内置浏览器、云端电脑、插件 | 浏览器和 Electron 用例覆盖客户端绘制的工具栏、分栏、资料库、文档预览和宿主界面。嵌入的第三方网页、插件自绘内容和操作系统对话框不在本次设计范围内。 |

示例截图由回归用例输出到 `test-results/`：`chat-send-queue-dark.png`、`chat-send-queue-short.png`、`workspace-home.png`、`workspace-page-小镇广场.png`、`town-firesides-dark-435.png`。

PPTX 缩略图在宽窗口验证了鼠标点击；窄窗口验证了布局和键盘切换。修改前后的无界面 Chrome 均未能稳定验证调整窗口大小后嵌入页的鼠标命中，因此该项不记作已通过。

发送气泡按参考截图使用 `#2177ec`。白色正文在这个底色上的对比度约为 4.27:1，低于常规文本的 4.5:1 目标。
