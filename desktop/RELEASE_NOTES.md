# Portal Desktop 0.1.3

本版聚焦 Portal 本地兼容、场景感知与 Town 协作体验，并修复近期在篝火反馈的若干问题。

## 重点更新

- **旧版 Portal 兼容与日志协作**：修复部分旧版 Portal 在本机启动、状态识别和运行衔接中的报错，增强客户端兼容处理；现在可将脱敏后的 Portal 日志直接放入当前对话，经用户确认后发送给 Being 协助排查。
- **接入场景感知**：客户端会区分 Being 当前所在的对话、Town、Kit、Portal 等场景，为对话和协作提供更准确的上下文。
- **Town 配对码自动获取**：连接 Being 后可自动获取 Town 配对码并完成配对；自动获取不可用时仍可手动输入。
- **修复私信“一起看”权限问题**：修复引用私信内容时被错误拦截的问题，保留内容预览和发送前确认。
- **修复对话框内容显示**：修复对话框中的 Markdown 格式及部分弹窗布局显示异常，改善长内容和分页场景下的阅读与操作体验。
- **体验优化与问题修复**：调整部分界面和交互细节，并修复其他已知问题，提升客户端的稳定性和日常使用体验。

## 升级提示

升级会短暂中断本机 Portal 任务，请先完成正在运行的任务并保存未发送的内容。Windows 和不同架构的 macOS 用户请下载与当前系统匹配的安装包。
