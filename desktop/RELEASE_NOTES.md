# Portal Desktop 0.1.5

相较 v0.1.4 的更新：

- 多场景对话：支持新建、重命名、删除场景和绑定已有场景 ID；切换时保留各场景草稿，后台回复继续进行，并显示场景运行状态。
- 跨场景上下文：在当前场景下开启“显示全部场景上下文”，查看其他场景消息；仍可正常输入，发送归属当前场景。
- 场景任务排队：其他场景忙碌时，新任务在客户端按顺序排队；保存正文、附件和所属场景，支持取消，发送结果不明确时避免自动重发。
- subagent 配置：增加启用开关、安装与模型配置入口；统一 Heart / subagent 模型设置，支持自定义接口和思考强度。
- 聊天稳定性：同步 Loom 1.8.2 对话处理；改善历史缓存、跨场景流式回复和恢复逻辑，修复附件读取期间编辑或删除导致的发送问题。
- Town 阅读体验：刷新时保留已有内容和展开状态，失败时继续显示上次内容；长消息按需渲染，增加消息复制，修复私信计数与筛选按钮对齐。
- 桌面与 Kit 兼容性：Windows 后台启动避免弹出控制台；关闭 macOS 透明窗口渲染；Kit 支持带 BOM 的清单及不同平台的启动命令。

更新 Portal 依赖，并补充场景、附件、模型配置和界面回归测试。
