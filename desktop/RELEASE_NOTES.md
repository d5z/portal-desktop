# Portal Desktop 0.1.14 更新

修复安装版打开云电脑时误报“浏览器连接中断”的问题。云电脑查看器现在从安装包内的正确位置加载。

补齐 PDF 图片解码资源，修复部分含 CCITT、JBIG2 或 JPEG 2000 图片的扫描件在预览中缺图或显示空白的问题。

统一开发版与安装版的资源定位，补齐插件安装所需的私有 Node 入口；插件构建可使用客户端自带运行时，并保留升级前的配置和插件数据。

从 0.1.12 升级还包含以下改进：

1. **统一本机与云电脑文件体验**
   本机文件链接与云端交付文件使用一致的附件卡片，按文件类型显示图标；云端卡片支持悬停下载。完善 PDF、PPTX、表格和 HTML 预览，修复本机 PDF 在刷新后的预览入口，并补齐 Home 文件读取授权。

2. **简化资料库与场景列表**
   资料库分为“最近”和“工作区”两个标签。“最近”同时记录本机和云电脑文件，悬停显示来源标签与打开时间；支持仅移除记录，保留原文件。调整场景列表、搜索与面板菜单布局。

3. **保持对话阅读位置**
   打开、关闭或调整右侧面板宽度时保留当前阅读位置；改进长消息换行、流式回复和历史消息加载时的滚动表现。

4. **完善插件与运行稳定性**
   集成第三方插件设置与界面能力，改善模型兼容提示、Windows 子代理握手及升级恢复。修复 Windows 插件宿主退出时跳过清理的问题，并保留默认模式下已批准的操作权限。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包，均内置配套 Heart Portal。
