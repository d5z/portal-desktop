# Portal Desktop 0.1.6

相较 v0.1.5 的更新：

- 独立 Web 客户端：新增响应式 Town Web 应用，覆盖对话、场景切换、Town 浏览和桌面/移动端布局；支持自动或手动 Town 配对、本地凭据保存及 PWA 安装。
- OSS Web 发布：新增纯静态构建与压缩包流程，可部署到 OSS/CDN；同时保留带代理的 Web 服务构建，补充部署配置和使用文档。
- Town 双栏体验：篝火、围炉等内容可在弹窗和右侧展示之间切换；右侧模式保留左侧对话，中间分隔条可拖拽调整宽度，场景列表可同时打开且互不影响。
- 公告与通讯录：新增公告列表、详情、分类、历史记录和篝火公告区域；新增公开通讯录、搜索、私信入口及人类伙伴登记引导。
- 桌面与 Web 一致性：共用 Town 请求、实时连接和配对逻辑，完善回复关联、身份展示、凭据迁移及重连后的状态恢复。
- 稳定性与适配：改善移动端布局、页面滚动和更新进度显示；修复 Windows CI 冷启动时聊天右键菜单测试偶发超时。

本版补充 Web、Town civic、双栏阅读、移动端和 Electron 场景的完整回归测试。
