# Portal Desktop 0.1.7

相较 v0.1.6 的更新：

- 场景切换上下文：当最新消息与全局上一条对话的 `scene_id` 不同时，在发送内容前加入轻量的场景提示；提示包含场景名称与 ID，不修改输入框中的自定义正文。
- 思考过程提示：场景切换上下文会在当前运行记录中以弱提示展示，方便确认 Being 实际收到的场景来源。
- 多场景排队一致性：立即发送、后台排队和手动重试共用同一份场景上下文，避免重试或出队后丢失提示。
- 重复消息修复：完善 SSE 实时回复与历史对账的双向去重；历史先到或实时流先到都只保留一条，并兼容规范场景 ID、旧场景 ID 与未标记历史。
- 历史身份合并：实时气泡对账成功后继承服务端 `seq` 和时间；明确属于不同场景的同文消息仍分别保留。
- Windows 后台升级：停止计划任务时同步终止经身份校验的 PowerShell 监督进程树，避免旧 Portal 被重新拉起并占用日志文件，确保升级和回滚可完成。

本版新增场景上下文、跨场景排队、网络重试、历史先于 `message_stop` 到达以及 Windows 原生升级/回滚的回归覆盖。
