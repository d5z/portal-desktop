# Portal Desktop 0.1.4

本版更新对话、Town 与 Grove 的日常体验，同时改善模型设置、桌面通知和 Portal 恢复。

- **对话与阅读**：正文和对话框支持右键菜单复制、粘贴；回复引用可展开查看完整消息并跳转到原消息。回复时可交给 Being 帮忙组织语言和上下文，再发送到相应对话。
- **围炉与通知**：围炉展示成员信息；私信和围炉消息可接入系统通知。桌面通知提供总开关及分类开关，默认关闭，开启后仅在窗口处于后台时提醒，不显示消息正文。
- **导航与外观**：弹窗支持前进、后退，并适配 Mac 触控板手势；更新客户端 Logo、系统图标和部分界面样式。
- **Grove 与生态**：同步 Grove 的目录变化，支持 App 类型，完善详情和评论展示；补充场景触发及生态相关的小功能。
- **模型配置**：支持自部署模型，并修复模型设置未生效的问题。
- **稳定性**：修复已知的 Town、菜单和布局问题。Windows 可强制关闭当前 Being 的旧 Portal 再启动内置引擎；恢复异常退出的后台 Portal，提供重启入口及启动诊断，同时保留其他 Being 的实例和已有配置。
