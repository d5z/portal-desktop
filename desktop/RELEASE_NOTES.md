# Portal Desktop 0.1.12 更新

1. **统一设置与配置保存体验**
   Being、Portal、Town、模型、外观和通用设置共用一个窗口。切换分类保留连接草稿，关闭时提示未保存修改；修复子代理开关保存后显示旧值的问题。

2. **改善对话阅读与消息操作**
   消息按时间分组，右键可复制正文并查看时间；选中文字可添加到聊天并保留原有草稿。支持切换思考链路显示，回到底部时收起已展开的历史消息。

3. **优化页面性能与文件预览**
   合并流式文本和日志更新，减少滚动测量及重复事件监听。PDF 解析器按需加载，关闭内置浏览器时停止布局监听，并减少代码高亮依赖。

4. **完善 Town 布局与运行稳定性**
   调整篝火、围炉和私信的消息布局、引用展开及固定标题；改善键盘焦点与设置标签导航。修复 Portal 追加文件时可能在写入完成前报告成功的问题。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包，均内置 Heart Portal。
