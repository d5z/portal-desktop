# Portal Desktop 0.1.8

相较 v0.1.7，0.1.8 重点重构了客户端布局与交互，让导航、对话阅读和工具切换更连贯；同时正式加入客户端插件支持，并修复多场景聊天、流式回复和界面显示中的一批问题。

## 布局重构，日常操作更顺手

- **统一工作区导航**：重新组织模块入口、场景选择和设置导航，减少在对话、社区与工具之间切换的操作成本。
- **可固定、可展开的侧栏**：常用模块支持固定到侧栏，导航可以展开，方便快速返回经常使用的功能。
- **可调整宽度的 Being 面板**：右侧面板可拖拽调整宽度，兼顾主工作区和 Being 对话；浅色、深色模式的控件样式也做了统一。
- **更一致的社区页面**：优化篝火、围炉、私信的间距、选中状态和内容展开体验；服务目录使用缓存与刷新机制，切换页面时更连贯。
- **Windows 显示优化**：调整字体回退、文字排版与图标渲染，改善不同平台上的显示一致性。

## 对话阅读更连贯，历史更好找

- **优化流式回复滚动**：回复较短时自然向下展开，长回复开始超出视野后稳定其阅读起点，减少内容生成过程中的跳动；手动滚动后可继续自主阅读。
- **回复片段合并展示**：同一条回复被工具调用分隔时，正文仍在同一个气泡中衔接，阅读更完整。
- **更清晰的新消息入口**：以最新消息计数和跳转入口替代原消息索引；停止生成与发送操作集中到输入区。
- **新增全局对话搜索**：查找历史内容更方便，并改进场景历史缓存与无场景标记消息的呈现。
- **历史加载可配置**：支持设置聊天历史每次加载的数量，保留增量加载与缓存；篝火加载数量也可调整。

## 支持客户端插件，扩展自己的工作台

- **统一工具库**：App、Kit、Plugin 集中管理，支持按类型和“仅本机存在”筛选。
- **插件安装与管理**：支持从本地导入插件或通过 Grove 下载，提供启用、停用、卸载和来源记录。
- **独立插件界面**：插件可提供页面和独立窗口，支持主题同步、插件私有存储、设置与命令入口；通过隔离加载和权限控制接入客户端能力。
- **插件与 Being 协作**：新增工作区上下文、资源协作侧栏、领域事件和场景任务状态接口，便于插件将自己的内容与 Being 对话、后台任务关联起来。
- **开发者 SDK**：提供 Plugin API v1、SDK 1.4 类型包和更新后的 API / SDK 指南，覆盖 Town 读取、Being 历史、草稿、确认发送与流式回复等能力。

插件需要单独安装，本版不内置社区星图等第三方插件。当前插件接口不直接兼容 Obsidian 或 Codex 插件包；插件自动更新、回退与签名仍在后续规划中。

## 模型设置与诊断更清晰

- **新版模型设置**：首页聚焦当前模型和思考深度，进入“更换”后按线路搜索模型，展示最近使用、模型能力、发布日期与目录未验证标记。
- **动态模型目录与试连**：接入服务端线路、模型目录和密钥接口，使用线路返回的原始模型 ID；支持先保存密钥再加载模型、试连后切换，以及失败时的候选模型提示。
- **密钥错误可恢复**：服务商拒绝已保存密钥时，可直接重新填写；切换失败或回退时保留服务端确认的配置，兼容旧版 Being 设置接口。
- **subagent 配置引导**：改善未启用时的提示、启动入口与配置流程，保留 Being 和本机 subagent 各自的配置。
- **完整日志导出**：支持将客户端与 Portal 运行日志导出为脱敏 ZIP，补充正常运行输出和请求追踪上下文，方便定位问题。

## Bug 修复与稳定性改进

- 修复流式回复、阶段性进展、最终回复与持久化历史对账时出现的重复消息和重复气泡。
- 改善服务端消息序号与实时消息的合并，减少跨场景切换及历史刷新后的显示不一致。
- 修复流式回复滚动锚点容易被触控板微小移动打断的问题。
- 改善多场景任务排队与恢复，修复工具上下文过期、已安装 Kit 页面选中状态和聊天内插件快捷键等问题。
- 修复模型状态指示点被挤压、部分 Windows 字体与图标显示异常，以及模型设置退出选择页后的键盘焦点问题。

## 安装与升级

- macOS 提供 Apple Silicon（arm64）和 Intel（x64）的 DMG / ZIP；Windows 提供 x64 安装程序和 ZIP。
- 安装包继续内置配套 Heart Portal。已安装用户可通过客户端“检查更新”升级。
- macOS 包使用 Developer ID 签名，公证仍暂缓；Windows Authenticode 签名尚未配置。
