# React Bits components

These files come from the reviewed Being Home worktree. The [bundled React Bits license](../react-bits-stack/LICENSE.md) applies.

| Component | Registry source | Being use |
| --- | --- | --- |
| Folder | [Folder-TS-CSS](https://reactbits.dev/r/Folder-TS-CSS) | Uses the existing compact opening and paper inset from the right sidebar review. |
| TiltedCard | [TiltedCard-TS-CSS](https://reactbits.dev/r/TiltedCard-TS-CSS) | Renders the library thumbnail and passes through its preview button action. |
| Glide Select | [GlideSelect-TS-CSS](https://reactbits.dev/r/GlideSelect-TS-CSS) | Moves the existing highlight between full-width configuration rows. |
| Warm Tooltip | [WarmTooltip-TS-CSS](https://reactbits.dev/r/WarmTooltip-TS-CSS) | Shares timing across the Dock and scene toolbar controls. |
| Status Mark | [StatusMark-TS-CSS](https://reactbits.dev/r/StatusMark-TS-CSS) | Animates the existing scene and tool execution status icons. |
| Gradual Blur | [GradualBlur-TS-CSS](https://reactbits.dev/r/GradualBlur-TS-CSS) | Reuses the chat design branch’s layers and curve. The reading controller provides the reveal amount for each edge. |
